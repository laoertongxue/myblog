# D14 模型选型边界实践包

Python 3.10+；仅标准库。在本目录运行：

```bash
python -m unittest -v
python run.py
sha256sum -c MANIFEST.sha256
```

run.py 也支持从任意工作目录按绝对路径执行。输出不含时间戳，可稳定重跑。测试采用 Fraction 的几何展开独立验证全部预测及28行指标，而非仅比较生产函数自身输出。

## 数据与边界

两份模拟 CSV 字节沿用D13，继承D9固定哈希。初始历史1—112天，验证113—140天。禾味是虚构2店8食材背景，本包仅计算A店SKU01，公斤/日；匿名服装是终端订单需求，件/日，不是生产排产。两案例不能合并评分。

原40天测试汇总已在D9曝光，开发段也已被反复查看。本包不含、读取或重评分原测试标签，不读取 sealed 目录。这里只做教学开发回放，不是新盲测、无偏泛化证明或业务收益验证。不会搜索新参数或实现SARIMA、Croston类、树模型。

七个既有候选：SNaive7，MA3/7/14，SES0.2/0.5/0.8。SES首观测初始化；MA和SES固定起点内保持水平，SNaive7复制最近同星期观测。跨起点使用新近已发生观测更新历史，固定起点内不使用未来实际或递归填回预测。

一步起点112—139，28个目标113—140；固定五日起点112—135，24个窗口113—117到136—140。每个窗口一次发布完整版本后才附实际评分。后4个起点没有完整五日目标，不纳入五日评分。24窗口互相重叠，不是24个独立样本，不能据排名直接推断显著性。

## 评分

误差e=实际−预测；ME=mean(e)，MAE=mean(|e|)，RMSE=sqrt(mean(e²))，WAPE=sum(|e|)/sum(实际)。WAPE保存比例而非百分数；分母0返回None/CSV空白，状态undefined_zero_actual_sum。五日先合计实际与预测再计算误差，单位公斤/件；并非逐日绝对误差相加。其WAPE分母重复覆盖重叠日期，不是唯一日期总量。相同案例相同任务内WAPE与MAE排序一致，但不能跨单位/任务比较绝对误差大小。

缺数、负需求、非有限值、混合实体、日期错位等拒绝输入；不补零、不做全样本平滑。metrics.py字节沿用D13；baseline.py以D13为基础增加SES非零状态归零检测，issue/replay增加case与series身份绑定且发布函数仅检查已验证历史。数值契约包括聚合有限、非零指标下溢报错；SES精确凸组合应为正但浮点更新归零时报ValueError，真实零以及alpha=0/1的有效端点仍允许。这里只检测归零，不提供任意精度或消除其他普通浮点舍入；例如原CSV中1e-400在float解析阶段可能已成为0，检测不能恢复输入解析前的值。该模拟数据完整观测，不解决销量被缺货截断问题，也未实现真实 available_at 延迟到达过滤。

## 输出

- results/metrics.csv：28行，2案例×7方法×2任务，MAE/ME/RMSE/WAPE齐全。
- results/predictions.csv：2072行，完整案例/实体/单位/参数/起点/目标日期/步长/预测/实际。
- results/window_totals.csv：728行，392个一步目标和336个五日窗口；另存逐日绝对误差和用于对照抵消。
- results/rankings.csv：56行，按案例、任务、MAE或RMSE排序；同分按方法名排，序号不代表统计显著。
- results/leakage_diagnostics.csv：336组，攻击未来标签/标记、无效未来对象和只传历史前缀，预测应不变；测试另覆盖最后4个一步起点和整次回放扰动。
- results/negative_control.json：起点117固定五日与之后每日更新的一步预测错误拼接，明确排除后者作为五日评分。
- results/run_manifest.json：输入哈希、候选、窗口、选择时点及结论边界。
- results/output_hashes.json：结果文件SHA-256（不自包含）。source_manifest.json记录输入固定哈希；MANIFEST.sha256记录整个实践包（不自包含）。

排名在全部预测生成之后才汇总，不传回 issue/replay。没有根据最终赢家重写历史选择。下一轮新增候选应先写协议，再使用尚未观察的新时间段评价；不能将已曝光的原测试段重新包装为盲测。

## 可观察的反例

服装一步：SNaive7 MAE=21.1071，小于SES0.8的24.0696；但RMSE=42.2717，大于SES0.8的37.9167。同一批数据换损失，胜者可变。服装五日：MA14 MAE=109.4524、RMSE=138.5447，两项均最小；一步MAE赢家SNaive7的五日MAE=115.8750。

禾味MA7一步MAE=5.3214略小于MA14的5.3852，五日则9.3750大于9.1518。这只是已查看验证段的排序，不是“MA14普遍更适合五日”的证明。
