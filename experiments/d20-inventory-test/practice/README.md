## 时间及初态

库存只运行153—180共28天（2026-09-05至2026-10-02），第153日初重置：禾味78公斤、服装316件，空在途，两策略相同，不继承验证终态，不做141—152库存热身。预测可以用已观察的原始需求1—152作为第153日前历史。

## 指标

平均现存=28个日末现存之和/28，不含在途，不是日内时间加权平均；数量满足率=履约/原始需求，零总需求为null；失销=原始需求-履约；订单次数只数非零下单。原始需求假设完整可见，缺货截断销量的实际项目需要额外观测模型。

预测评分分别为单日40个起点140—179，固定五日累计36个起点140—175。每个五日窗口固定起点一次发出5步，不偷用窗口内新观测，目标始终在141—180内；窗口重叠不是独立样本。误差=实际-预测，MAE为绝对误差平均，RMSE为平方误差平均再开方，ME为有符号误差平均。

`output/results.json`为四组库存指标；`ledger.csv`共112行；`order_events.csv`为订单/到货事件；`pending.csv`为180日末尾单；`forecast_windows.csv`共152行（两案×76窗口）；`forecast_metrics.json`为预测指标；`validation_test_comparison.json`只对照四个冻结组，不用测试重排参数；`execution_receipt.json`记录源哈希及输出哈希。所有CSV使用LF，JSON使用固定排序。

## 如何解释

禾味验证时两策略均零失销，测试分别失销5和8公斤；每日少失销3公斤且平均现存较低，但多下5次单，无成本模型不能宣称经济更优。服装每日策略少失销4件，却多约57.21件平均现存；平均现存、末现存及末在途不可互换。测试结果不满意也保留原参数，后续研究另起新协议与独立评估数据。

测试含独立日历重算、守恒、尾单、时序、等号触发、每日一单、复核相位、未来扰动、销量独立、零需求、输入拒绝、重复复算与篡改拒绝。通过这些检查不代表生产上线安全、真实经营收益或长期服务保证。
