# 第五篇：从预测到受约束补货建议（可复现实验）

所有数据均为本篇全新构造的教学模拟。虚构「禾味」背景为 2 店、8 种食材，实际演算只覆盖 A 店 SKU01；服装例仅为匿名单款单码。没有训练预测模型，没有真实经营数据，没有真实收益、独立盲测或上线效果声明。

## 运行

要求 Python 3.10+，仅使用标准库，无须安装依赖。进入本目录后：

```bash
python run.py --inputs inputs --output rerun_results
python -m unittest discover -s tests -v
```

`results/` 是随包附带的一次实跑结果。重跑请换一个**尚不存在**的输出目录，例如 `rerun_results_2`。脚本拒绝覆盖已有输出，拒绝把输出放在输入目录中、输入目录上层或代码上层；也会解析符号链接以识别冲突。不会重建、重置或修改输入 CSV。可复制 `inputs/` 后修改副本，使用 `--inputs` 指定它。非法输入会在创建输出之前报错。

## 文件

- `inputs/`：7 张完整输入表，字段逐项解释见 `DATA_DICTIONARY.md`。
- `run.py`：加权经验分位数、报童期望成本、逐日 FEFO 库存、服装用料计算。
- `tests/test_run.py`：72 项单元与文件集成测试。
- `results/summary.json`：汇总结果，Decimal 作为字符串存储，以保留精度。
- `results/newsvendor.csv`：报童候选、期望短缺、期望剩余、期望成本。
- `results/inventory_candidates.csv`：所有枚举候选的可行性、拒绝原因、损失和过期。
- `results/apparel_plans.csv`：完整目标备料与产能内70件方案并列。
- `inputs_expiry_pressure/` 与 `results_expiry_pressure/`：仅把日1需求从12改为6kg的完整输入和独立实跑结果。
- `results/inventory_ledger.csv`：所有候选 × 所有天的完整日账，含 FEFO 批次扣减。
- `REPORT.md`：本次实跑解读及边界。

## 时间、目标和约定

起点为 **2026-11-12 第1日08:00**，营业前盘点并下单。提前期 L=1 个完整日，新单在 11月13日08:00（第2日）到货。检查周期 R=2，下一次检查为 11月14日08:00（第3日），该次新单最早第4日08:00到货。因此本次保护第1–3日，H=L+R=3。`day=1` 对应上述起点，不是「第0日日终下单」。

三日需求 `[12,14,10] kg` 是起点**事先冻结的确定性计划情景**，不是事后实际销量或回测标签。该情景不包含概率、不声称服务水平。模拟先到货并检查瞬时容量，再按先到期先出（FEFO）满足当天需求，最后处理当日日终过期。当天失销不延期，不会被后一天到货抵消。

订单按 5kg 枚举 0 至 30kg；正订单至少 10kg。违反包规、MOQ 或任一天到货瞬时容量的候选一律不可执行。为了说明哪里失败，程序仍计算这些候选的**反事实诊断轨迹**，不将它们视为执行结果。可行候选按「总失销量最少 → 过期量最少 → 订单量最少」排序。这是明示的教学选择规则，不是经过经济成本标定的最优政策。

分位数采用**逆经验分布函数**：累计权重首次达到目标分位数的位置，不插值。输入及库存账本使用 `Decimal`；报童临界分位数、期望成本比较、服装用料缺口和包规上整采用标准库 `Fraction` 精确有理数计算；不对中间用料数量取整，只在最终包规/卷长处向上取整。Decimal 工作精度为60位有效数字，循环小数仅在输出展示时按该精度表示，不将这些显示值回送分位数、成本并列判断或采购取整。服装期望情景可非整数，本例恰为100件，不可将其称为高分位需求。

## 模型边界

本例只演示单品、固定提前期、已知保质期、冻结计划和确定容量。不处理供应商拒单、到货波动、负库存、跨店调拨、替代、欠单、整件生产排程、多SKU联合容量或共享预算。服装材料采购是假设本次采购可及时投入的备料建议，不证明产能、工序或供应提前期足以按时交货。要投入业务，应将这些约束补入并通过实际数据校验。

## 输入边界与额外实验

公开练习包采用明确的有限输入域：所有数值使用普通十进制文本，范围0至1,000,000，最多6位小数，不接受指数形式。概率另限[0,1]，利用率与两项报童成本必须严格为正，故临界分位数严格在(0,1)内，零成本端点不在此练习支持范围。每文件最多1MiB、1000行；单个枚举最多1000个候选；库存保护期最多366日、候选×天数最多100000行。CSV严格解析，拒绝破损引号。输入异常均在创建输出前失败。

效期压力复现（只改变第1日需求为6kg）：

```bash
python run.py --inputs inputs_expiry_pressure --output pressure_rerun
```

该计划下15kg仍为所枚举可行候选中失销最少方案，第1日剩4kg日终报废，第3日仍缺1kg。期外库存不能复活抵扣。

`apparel_plans.csv` 同时列出85件完整目标备料（采购100m）与产能内70件方案（毛料147.368421…m，缺67.368421…m，采购80m，仍有15件情景需求未覆盖）。产能内方案也只是材料与产能数量约束的计划检查，不保证供应时效、工序或真实交付。

候选选择严格限于输入枚举范围。汇总中的 `inventory_enumeration` 报告范围与可能截断警告：当上限小于容量可容纳的最大合规格包量时，扩大枚举上限后再讨论建议，不能称为全局最优。所有批次及路径ID使用64字符以内ASCII白名单，防止导出CSV公式注入。

## 精确边界回归

临界分位数不先计算舍入后的Cu/(Cu+Co)，而用精确分数比较累计权重。成本先精确计算加权损失，候选并列也比较精确有理数，最后才转换成显示用小数。采购上整直接对精确“缺口/包规”分数的整数分子、分母求上整；服装毛耗到及时净缺口保留Fraction，不能从展示小数重新计算取整。

72项测试包含两项独立报童回归：Cu=2、Co=15，需求80/100权重2/15时临界分位数为80；Cu=1、Co=5，需求80/100权重1/5时80至100步长5的全部候选并列成本100/6。另以小于Decimal显示精度的边界偏差验证包规上整。CSV用户输入仍受6位小数限制；超精度边界测试直接针对内部算术函数，未放宽输入范围。
