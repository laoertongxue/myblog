# 第9篇间歇需求实验
全部模拟。Python 3.10+，标准库，执行 `python run.py` 然后 `python -m unittest -v`。
生成器固定算术序列：两个180天单序列，不是完整门店SKU面板。训练112、验证28、测试40；5天窗口不跨分块；验证末3天不评分。实际观测进入后续滚动状态，但测试期不重选型。TSB beta=alpha；初始化为首事件量、首事件日序号、其倒数。零历史预测0为操作约定，不是未来无需求保证。
运行会覆写本目录 data.json、results.json、predictions.csv，请在副本上做新实验。所有结果可由生成器重建；测试文件包含未来扰动、边界和手算检查。
本实验不计算库存收益、概率校准或分位数。全零和菜单日历需单独业务处理。生成器包含周期性但模型未使用已知日历，不可宣称优于日历模型。
