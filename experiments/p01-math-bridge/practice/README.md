# 数学桥梁：读者练习包

这里只做手算与数据核验，未训练模型，未验证真实业务效果。案例、数量、预测与概率全部为教学模拟。

## 从零运行

需要 Python 3.10 或更新版本，仅使用标准库，不用安装第三方依赖。解压后，在本 README 所在目录打开终端：

```bash
python3 run.py
python3 -m unittest -v test_practice.py
```

Windows 可将所有命令中的 `python3` 替换为 `py`；若只配置了 `python`，则替换为 `python`。脚本默认从自身旁的 `data/` 读取三个 CSV，生成或覆盖自身旁的 `results/math_checks.csv` 与 `results/results.json`。第二条命令的输入攻击都在临时副本中进行，不改原始 CSV。

另存实验结果可用：

```bash
python3 run.py --data-dir data --out-dir my-results
```

命令有错会返回非零退出码。修改数据后若运行失败，原有结果不会被自动删除，不能把旧结果当成新一轮成功输出。先看退出状态，再读结果。

## 明确支持的输入范围与计算精度

这是一份有界的教学计算器，不是接收任意数量级实数的通用数值库。对CSV中原始十进制文字精确检查，拒绝越界或多余精度，不自动舍入为可接受值。

| 输入 | 支持范围 | 步长与处理 |
|---|---|---|
| 禾味actual、forecast | 0至1,000,000公斤，含端点 | 必须是0.001公斤的整数倍；转为整数克计算 |
| 禾味weight | 0至1，含端点 | 必须是0.000001的整数倍；转为整数百万分之一，三项精确合计1,000,000 |
| day、订单笔数 | 非负十进制整数字符串，最大2^53−1 | 仍须满足指定天数、非空风险集、跨天连续及数量守恒 |

例如0、0.001、1.0000、999999.999和1e6公斤有效；0.0005、2.5e-162、5e-324、1e308、1000000.001及“看起来可舍入到端点”的额外小数均无效。0.2、0.3、0.5是有效权重；0.333333333333不是本包支持的权重精度。输入约束不限制数学定义的适用范围，也不把输出均值强行截为三位小数。

需求、预测、误差、平方和及方差分子都先以Python整数精确运算，再将最终比值换回公斤，平方根使用标准库。这样100万公斤附近相差1克也不会在相减时丢失；方差不对两个接近的大浮点数直接相减。服装留存概率用末日剩余单数除以初始风险集，期望先乘整数分子再除分母，避免用接近1的取消率做1减法损失精度。输出仍为普通浮点数，允许正常末位舍入，不承诺实数的无限精度。

CSV按严格模式解析，末格未闭合引号（例如`"30`）或闭合引号后的非法字符会报错；正确配对的`"30"`仍可读取。输入错误返回退出码2，不写新的成功结果；原输出文件可能保留，必须先确认本次命令成功，不能误读旧文件。

## 两个案例、三份输入

| 文件 | 一行是什么 | 字段与单位 |
|---|---|---|
| `data/hewei.csv` | 虚构禾味 A 店鸡腿肉某一天的记录 | `day` 为第几天；`series` 为序列键；`unit=kg`；`actual` 是当天实际需求公斤数；`forecast` 是该天既有预测公斤数；`weight` 是无单位权重 |
| `data/apparel.csv` | 匿名服装 S01-M 批次某一天的取消记录 | `unit=order` 表示订单笔数；`risk_start` 为日初仍未取消的订单数；`cancel` 为当日取消数；`remaining` 为日末剩余数 |
| `data/new_batch.csv` | 同一服装序列的一个新模拟批次 | `orders` 为新批次初始订单数，默认 30 单 |

订单数和day字段必须使用非负十进制整数字符串（如100，不写100.0或1e2），且不超过2^53−1；避免浮点解析悄悄吞掉小数或改变大整数。

`hewei.csv` 固定三行、按第1至3天排列，`apparel.csv` 固定两行、按第1至2天排列。它们是本篇限定的小作业，不是可接受任意长度、任意企业数据的通用管线。每日公斤数可以平均，得到“每个观察日的平均需求公斤数”；平方后的方差单位为 kg²，标准差及误差指标单位为 kg。服装按订单笔数统计，不是商品件数；多件订单不能直接把单数当件数。

实际需求假定完全可见。这里没有库存截断、报表延迟、预测生成时点及模型拟合；`forecast` 是题目给定待评分的值，不是脚本从 `actual` 拟合出来的值。真实预测必须另保留预测起点与当时可用信息。

服装例假设两天中只有取消这一种退出方式，无发货、缺测、删失、新增或恢复订单。因此下一天风险集恰好等于前一天剩余数。它不能直接替代生产环境的生存分析。

## 先手算，再看输出

1. 禾味实际是 10、12、14 kg。求和 36，除以 3 得到均值 12 kg。加权平均为 `0.2×10+0.3×12+0.5×14=12.6 kg`。权重来自题设，不是调参得到的“最优权重”。
2. 预测是 11、11、13 kg。误差统一采用实际减预测，得到 −1、1、1 kg；负号代表高估，正号代表低估。绝对误差都是1，平方误差都是1；MAE 与 RMSE 都为1 kg。`math_checks.csv` 包含这些逐行结果。
3. 实际值减均值得到 −2、0、2 kg，平方和为8 kg²。把这三天当作完整总体，方差为8÷3，标准差约1.632993 kg；若把三天当样本估计总体波动，样本方差为8÷(3−1)=4 kg²，样本标准差为2 kg。标准差不是预测误差。
4. 服装第1天风险集100单，取消10单，剩90单；第2天风险集90单，取消9单，剩81单。条件取消率分别为10÷100=0.1、9÷90=0.1；第二天取消数占初始批次的9÷100=0.09是另一个口径。
5. **假设**这两个条件取消概率能用于新的30单批次，连续留存概率为0.9×0.9=0.81，期望留存为30×0.81=24.3单。两天观测的实际剩余是81单；新批次的24.3是期望，不是实际或拣货指令。第二个0.9已经以“活过第一天”为条件，不需要另假设两天取消事件独立。将小样本概率推广到新批次仍是未经业务验证的教学假设。

`results.json` 还记录几个与输入 CSV 无关、在代码中明确标注的固定定义例题：误差−3、1得到 MAE=2、RMSE=√5≈2.236068 kg；f(x)=2x+3 时 f(4)=11；2³=8；log₂8=3；ln1=0；logit(0.5)=0；logit(0.8)=ln4≈1.386294；sigmoid(ln4)=0.8。这些固定例题不能用来判断修改 CSV 后程序是否正确读取数据。

`logit(p)=ln(p/(1−p))` 只允许 0<p<1。概率本身可取0和1，但这两个端点不能代入有限实数的 logit。sigmoid 把分数 z 映射回概率，代码分正负计算，避免 exp(1000) 溢出。精确数学中有限 z 的结果严格在0和1之间；计算机浮点数对极大正负分数可能舍入为1或0，这不代表绝对确定的业务结论。

## 交作业

先保存原 CSV，再另存修改版，逐项运行并记录“手算预期、程序输出、解释”：

- 把禾味三天实际与预测都加5，均值应为17、加权平均为17.6 kg，误差与标准差不变。
- 把实际与预测都乘2，均值为24、加权平均为25.2 kg，标准差与 MAE/RMSE 都乘2，方差乘4。
- 把新批次改为10单，期望留存应为8.1单。
- 在副本中把第2天风险集从90改为100并把剩余改为91，虽然这行内部满足减法，仍应因跨天风险集不连续而报错。
- 用自己的话说明：为什么第2天是9÷90；为什么波动1.63 kg和误差1 kg不是同一个数；为什么24.3单不能直接下达成24.3单。

验收要求：默认数值逐项一致；修改输入后结果按预期变化；异常输入失败而不是悄悄填零；解释误差方向、方差分母、概率条件与期望的含义。通过本作业只说明理解这些算术，不说明已掌握预测模型或生产补货。
