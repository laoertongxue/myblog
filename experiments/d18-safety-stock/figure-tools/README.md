# D18 黑白图稿复现

四图均为原创教学模拟图，不含真实品牌或业务数据。封面原生设计为900×383，正文为700像素宽竖版图，最小正文文字31像素。SVG保留可编辑文字，PNG由同一坐标的Pillow双倍超采样生成。

依赖Python、Pillow、fontTools，以及完整简体中文Noto Sans CJK SC字体。字体不随包分发。运行：

```sh
python figure-tools/render_figures.py --font-path /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc --font-index 2
```

TTC字体索引以所用字体文件为准，独立SC字体通常为0。脚本校验字体族、所有字形、文字边界、任意文本框重叠以及RGB三通道一致。输出到脚本上一级images，不依赖当前工作目录；只有识别到站点仓库才同步文章图片与封面源。

输出包括原图、可编辑SVG、280/350像素预览与质量报告。质量报告证明已覆盖的机器检查，不代表所有图形碰撞已经自动检测；边框、文字与手机阅读还需逐图像素检查。

指标图为独立四周期算例，不是主回放。公式图的σ日=2来自九条模拟训练样本，使用n−1样本方差；z=1.645只用于正态分位解释，不承诺失销回放达标。先验证冻结再测试是正式实验流程，本篇不执行未见测试。
