# 第8篇：层级预测协调实验

Python 3.10+，只用标准库。所有数据、总部预测、叶子预测、实际值和容量均为人为构造的教学模拟。匿名服装企业不是实际企业项目；禾味为虚构餐饮品牌。

## 运行

进入本目录：

```sh
python run.py
python -m unittest -v
```

重新生成独立输入，须给不存在或空目录：

```sh
python run.py --generate fresh_data
python run.py --data fresh_data --out fresh_outputs
```

默认运算不覆盖输入，输出目录不能在输入目录内。再次运行会覆盖指定输出CSV，不涉及生产系统。先复制数据再自行改参。

## 实验边界

这是构造截面与14天面板的算术/合同测试，不是预测模型训练、滚动回测或盲测。尤其实际值刻意等于叶子原始预测，用来构造“一致但更不准”的反例，不代表 bottom-up 在业务中更好，也不是通过观察未来产生可部署预测。没有估计协调权重、误差协方差或 MinT，没有概率分位数协调。固定 w=0.6 只是规则。

若后续比较方法准确性，另用180天模拟面板，1—112训练、113—140验证、141—180测试，5天评价窗口不跨分块，验证冻结后测试。这个包没有实现该实验。

## 数据与单位

- `data/leaves.csv`：236行。主键 case/day/sku/leaf。服装1个期间×6个SKU（黑/白×S/M/L）×2地区=12行；禾味14天×8食材SKU×2店=224行。
- `data/groups.csv`：118行。主键 case/day/sku；总部总量total、给定权重weight、单位unit、出品率yield_rate。
- 禾味8种食材为牛奶、椰浆、咖啡豆、红茶叶、糖浆、柠檬、珍珠、燕麦奶。每种原料均按其可用净料千克记账，每个SKU独立协调。柠檬出品率0.8，其余1为演算假设，不是实际工艺值。
- 服装单位件，不与kg混加。混合总量必须为整数才能执行最大余数；脚本不偷偷给小数总部总量选取整政策。
- base=叶子原始点预测，actual=构造观察量，stock=可用净料/件，capacity=本期可提供的净量。capacity每个SKU独立给定，并非多SKU共享仓容。
- 无在途、提前期、箱规、MOQ或损耗动态；毛料需求=gross_requirement，采购尚未实施。不能把需求协调等同于采购执行。

服装 `day=1` 是一个“未来7天”的单期间标签，不是一天的销量；该表没有逐日拆分。禾味 `day=1..14` 则是14个日粒度教学截面。二者是独立案例，不可沿day直接拼接为同粒度面板。

本包固定网格合同：服装仅day=1、黑白两色/SML三码、north/south两地区、piece单位；禾味必须day=1..14、列明的8食材、store_A/store_B两店、kg单位。缺组、错ID、改单位、重复主键均拒绝；扩展企业案例需显式改合同，不可静默忽略。

## 三条规则

bottom_up：总量为叶子之和，叶子不变。
fixed：锁总部总量，各叶子按原预测份额分。
mixed：协调总量=0.6×总部+0.4×叶子总量，再按原份额分。
整数服装先向下取整，再按小数余数从大到小分剩余件；并列按叶子ID升序。浮点余数在12位小数比较，以避免机器舍入破坏预期平局。

## 手算检查

黑色M码原北60/南50，总部100：bottom_up=60/50；fixed=55/45；mixed总量104，结果57/47。构造实际为60/50，对应叶子绝对误差之和0/10/6件。北方净供给容量50，则fixed缺口5件，不把55件预测压成50。

禾味第1天牛奶原18/14，总部30：fixed=16.875/13.125；mixed总量30.8，分17.325/13.475。北/南地区与门店A/B不是同一业务实体。

## 输出

`outputs/reconciled.csv`：708行（三方法×236叶子），adjustment=协调后−原叶子预测。
`outputs/group_checks.csv`：354行（三方法×118组），每个SKU每一天独立检查一致性及误差，不输出跨SKU“总误差胜率”。
`outputs/accuracy_counterexamples.csv`：两组反例共6行，反例1实际60/50，BU/fixed/mixed的MAE为0/5/3；反例2实际55/45，则MAE为5/0/2。第二组独立构造，不修改原面板actual；演示不同实际情形会改变胜者，并非统计胜率。
`outputs/metadata.json`：范围、行数、警示。
`test-report.txt`：本包生成时的28条测试记录。请在自己的机器重跑，不把记录当作重新运行。

所有小数用于计算不提前四舍五入；展示可保留3位，核对使用完整数。没有置信区间或泛化效果声明。

浮点数边界：先计算份额再乘总量，避免不必要的中间乘积溢出。叶子合计、协调总量、叶子结果和毛需求若超出有限浮点范围则显式报错，不输出Infinity。教学范围不支持任意精度大整数。
