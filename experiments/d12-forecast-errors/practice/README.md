## 数据与方法

`data/` 仅有原系列第 1—140 天，共 112 天初始历史与 28 天验证；字节沿用 D11，并核对 D9/D10 的固定 SHA-256。`source_manifest.json` 描述来源。本包不含原第 141—180 天标签、读取入口或评分命令。D9 已展示原测试段汇总，不得再称其全新盲测。

全部已有候选同时展示，不重新挑参数：季节性朴素周期7；MA窗口3、7、14；SES α为0.2、0.5、0.8，首个观测初始化。MA与SES固定起点五步均为相同水平，不用未来实际或预测值递归更新。

单日起点112—139，目标113—140（2026-07-27至08-23）；每得到一天实际后才能更新下一起点。分组以目标日星期为准：周一至周五20天，周六周日8天，不考虑节假日调休。五日窗口起点112—135，目标从113—117至136—140，共24个重叠窗口，不是独立样本。

## 指标契约

误差 e=实际−预测。正ME为平均低估，负ME为平均高估；样本ME为零不证明统计无偏，也不证明准确。

MAE=mean(|e|)，RMSE=sqrt(mean(e²))，ME=mean(e)，单位同单日需求（公斤/日或件/日）。WAPE=sum(|e|)/sum(实际)，保存为比例（0.4=40%）。仅接受非负实际，零需求行保留；实际总量为零返回 `None`（JSON为null、CSV为空）且状态为 `undefined_zero_actual_sum`，不加ε，不冒充0%。预测允许有限负值，保留其真实误差。计算使用Python浮点（通常为IEEE 754 binary64），保留正常舍入，不提供任意精度保证。ME、MAE先用math.fsum聚合再除以n；RMSE用最大绝对误差缩放以避免直接平方溢出。实际合计、绝对误差合计等聚合和必须有限，即使某个平均值单独可表示也不放宽这条契约。非零ME、MAE、RMSE或WAPE若下溢成零则报错；合法的正负抵消ME为零仍保留。空数组、长度不等、布尔值、非数字、NaN、无穷、负实际与计算溢出均报错。

指标函数按位置配对，不携带日期或单位；调用方必须先对齐。本实验 `compare` 从同一目标行生成所有候选，逐条保留日期、实体、单位，不拼接不同案例。原CSV入口要求连续唯一有序日期、非负有限需求、112/28分块。完全空白物理行由标准CSV读取器跳过；空格行和缺失日期仍报错。

同一组目标下 WAPE=MAE/平均实际，因此两者排名一致。跨组、跨期的分母变化会改变WAPE，不代表模型改进。总体ME、MAE按样本数加权；RMSE先合并平方误差再开根；WAPE合并分子分母，不平均百分数。不同单位不能合并。

## 结果文件

- `daily_predictions.csv`：392行=2案例×7候选×28目标，含带符号误差。
- `metrics.csv`：42行=2×7×3组，保留n、实际合计、绝对误差合计、四指标与WAPE状态。
- `validation_summary.json`：完整精度指标、参数、输入哈希和运行编号。
- `five_day_windows.csv`：336行=2×7×24，逐步预测与实际、合计及带符号合计误差。属于单独的五天总量任务；不把五个逐日修订预测拼成固定起点预测。本篇主表不对这些窗口作模型排名。
- `manual_oracle.json`：手算示例的字面预期，不是业务观测。

测试使用独立 Fraction 几何权重展开，核对全部392个单日预测、42行指标及五日预测。还检验误差方向、零需求、全零分母、异常输入、分组汇总、排名反转、未来污染和时间边界。通过测试不等于审查通过或真实业务有效。
