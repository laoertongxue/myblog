禾味教学数据 v1 · 2026-11-06

hewei-180d.csv 是完全模拟的演示数据，不是企业真实数据，也不是历史D9—D13文章原始实验文件。
规模：2门店 × 8食材SKU × 180天 = 2,880行。
字段：day为序号1至180，day1设为星期一；store_id门店；sku_id食材；demand_kg为未受库存约束的合成净需求，单位kg；split为训练/验证/历史演示测试；simulated始终True。

数据公式（确定性，无随机种子）：
8 + sku编号×1.3 + 门店编号 + 周末增量3 + 天序号×0.015 + (((天序号×17 + sku编号×11 + 门店编号×3) mod 9)-4)×0.3。
最后保留两位小数。mod为除法余数。周末为每7天中的第6、7天。

此数据具备刻意设定的周周期、微弱趋势与离散扰动，不代表现实复杂性。没有价格、库存、缺货、订单事件、available_at或供应端字段，不能用它声称验证了这些功能。

第1至112天为训练；113至140天验证；141至180天为已公开的历史演示测试，不是封存盲测。5天窗口必须完整处于同一分块。若需要独立最终评价，先冻结完整方案，再独立生成并保管新的挑战测试数据。

正文中的14天手算样本是独立样本，不是此CSV的前14天。本站同时提供P01/P03污染数据与回测作业包、六行业起步数据和专项手算包。各包有自己的字段、行数、模拟机制与README，不能混称同一个数据集。专项大样本训练与部分高级模型为选修扩展，并未声称完整实现。
