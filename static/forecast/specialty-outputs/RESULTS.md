# 实际运行结果：固定种子的模拟实验

本页由代码读取本次指标生成，不是预先填写的“理想成绩”。本次种子为20261106。所有数据虚构，没有真实企业效果或生产动作。

## 1. 预售：预测误差小不等于假设正确

- 同一批20,000订单，各有独立发货/信息性发货两个场景。每个场景训练6858单、验证1676单、测试4907单；其他日期记录保留作成熟空档和事件账。
- 独立发货：测试每日hazard Brier，平滑模型0.009135，总体基线0.009136。
- 信息性发货：测试每日hazard Brier，平滑模型0.007620，总体基线0.007613。本次平滑误差不低于总体。
- 第59日“无发货自然留存”估计减模拟潜在真值：独立场景0.06个百分点，信息性场景9.23个百分点。正数表示高估，负数表示低估。
- 两场景的风险集不同，不能拿两种场景的Brier直接排名。Oracle比较是模拟诊断，不是现实可以拿到的答案。

查看：`presale/survival.svg`、`presale/oracle_diagnostic_survival.csv`、`presale/conditional_pending_demand_scenario.csv`。

## 2. 退货：单件概率与日回流分开看

- 测试2612个发货行。退货Brier：分组0.144113，总体0.153057。
- 测试批次日回流MAE：分组1.926件/日，总体1.921件/日，不回流基线5.243件/日。本次分组误差不低于总体。
- 测试批次预计最终回流387.76件，实际367件；日回流WAPE为36.73%。实际回流总量为0时，WAPE分母为0而无定义，仍可报告MAE。
- 第180日起下一周按当前状态预测：日MAE 2.163件/日；无历史支持实体数0。这是另一个预测起点和口径，不与上项混比。

查看：`returns/daily_restock.svg`、`returns/test_cohort_daily_restock.csv`、`returns/state_conditioned_next7_daily.csv`。

## 3. COD：校准后也可能变差

- 测试2194包裹，实际拒收率18.64%。
- Brier：训练均值基线0.153947；未校准逻辑回归0.149606；验证集截距校准后0.152524。本次校准后未改善，保留结果，不按测试答案反选模型。
- 验证集冻结复核阈值为0.00。本次选到0，即全部建议复核。工作量为测试样本的100%。
- 假想成本：按冻结阈值15568.00元，不复核27950.00元，全复核15568.00元。冻结策略与全复核相同，不能把差额宣称成模型增量价值。
- 成本假设：每包复核2元、每件拒收损失25元、复核可减少真实拒收损失的60%。未模拟复核容量或人工效果实验，数字不是已实现节省。

查看：`cod/calibration.svg`、`cod/test_calibration.csv`、`cod/validation_threshold_costs.csv`，以及三张单独的库存/在途/预期销售图。

## 4. PO：不确定的P90就留空

- 测试335条PO，截止时49条未收齐；训练截止时60条未收齐。
- 验证集按30天内收齐Brier选择supplier KM。P50覆盖率52.54%，目标50%。
- P90可估计221/335条，不可估计114条，必须披露这个分母。可估计部分的实际覆盖率界为83.26%–93.21%；其中22条观察不足以判定。P90留空原因是训练KM曲线未达到90%收齐概率；没有可估计预测时不报告覆盖率，不用0或最大观察日填补。这个区间不是统计置信区间。
- 只用已完成训练PO的朴素P90，在全测试集覆盖79.10%，低于目标90%。若训练没有已完成PO，该分位数与覆盖率均不可估计。
- 没有统一“最好模型”结论：覆盖只对有可估计预测的样本描述；仅已完成样本的pinball有选择偏差风险。

查看：`po/test_po_predictions.csv`、`po/coverage_bounds.csv`、`po/km_survival.svg`。
