## 本周思考

这是第一期 Weekly。重新开始搭建个人网站，用 Hugo + Hextra 作为技术栈。

选择静态网站生成器的原因很简单：

- 内容 ownership 在自己手里
- 不依赖数据库
- 部署简单，性能优秀
- Markdown 写作体验好

## 本周发现

- Hugo 的构建速度确实很快
- Hextra 主题简洁美观，适合中文阅读
- GitHub Actions 可以实现完整的自动化发布流程
