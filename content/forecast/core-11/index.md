<p>覆盖
A10。目标是理解营销也会消耗库存，不能因为点击便宜就无限推销缺货商品。</p>
<h3 id="先定义增量与资源">1 先定义增量与资源</h3>
<p>主计划满足基础需求后，另行圈定柠檬茶6瓶、桃茶9瓶作为一个小营销实验的可用库存，不能把它们同时承诺给基础订单。总曝光600次，以100次为一块。曝光是被展示次数，不是独立人数UV；一个人可能看多次。</p>
<p>假设每100次曝光分别新增柠檬茶2瓶、桃茶3瓶需求；每瓶毛贡献分别4元、3元；每曝光块成本1元。这些转化率是<strong>指定的合成响应</strong>，不是从观察相关性得出的真实因果增量。实际需要随机试验或可靠因果估计。</p>
<p>xL、xP为给两商品的曝光块数，必须是整数。各至少1块以保留教学中的公平约束，各至多5块，总和不超过6。</p>
<h3 id="约束与目标逐项写">2 约束与目标逐项写</h3>
<p>库存约束：<code>2xL ≤ 6</code>，<code>3xP ≤ 9</code>，所以两者最多都只能3块。</p>
<p>预算约束：<code>xL+xP ≤ 6</code>。公平/平台约束：<code>1≤xL≤5</code>、<code>1≤xP≤5</code>。</p>
<p>预期净贡献：<code>4×2xL + 3×3xP − 1×(xL+xP) = 7xL + 8xP</code>，单位元。每个乘法的单位依次是元/瓶×瓶/块×块。</p>
<p>程序枚举所有组合，最优(3,3)：300次曝光给各商品，新增6和9瓶，贡献24+27−6=45元。若忘记库存限制，会想给桃茶5块，其新增15瓶超过可用9瓶，建议不可执行。</p>
<h3 id="转化比预计高也可能是风险">3 转化比预计高也可能是风险</h3>
<p>压力情景设每块分别新增3瓶、4瓶。要求在这一较高转化情景下仍不超库存，则3xL≤6、4xP≤9，最大都为2块。最优(2,2)，只用400次曝光，保留200次不用；按原均值计算净贡献30元。</p>
<p>资源没用满不一定是错误。如果库存不足，强行花完预算会产生超卖。可以提出补货或重新分配其他商品，但必须更新库存版本、到货时点与批准，不可假设补货必到。</p>
<h3 id="与供应计划如何相连">4 与供应计划如何相连</h3>
<p>本章分配的是基础预测之外的增量曝光和圈定库存。若要把营销增量并入主计划，应写
<code>总需求=基础需求+经验证的增量需求</code>，再重新检查补货和产能。反过来，供应短缺也能收紧曝光上界。不能用营销增加后的销量重新当“无营销自然需求”，否则下轮会重复放大。</p>
<h3 id="项目和答案">5 项目和答案</h3>
<p>输入 config的 <code>exposure</code>，输出 <code>traffic</code> 与
<code>traffic_robust</code>。把桃茶圈定库存改3，xP最多1；剩余曝光也不能自动塞给柠檬茶超过其3块上限。把总预算改1块，同时要求两商品各至少1块，答案是INFEASIBLE，不是返回0并说已优化。</p>
<p>练习：600次曝光是否等于600位顾客？答案不是；本包没有UV去重。能否把45元说成真实新增利润？不能，它只在指定合成转化、毛贡献和成本条件下成立。</p>
<p><strong>边界：</strong>
没有真实搜索排名、推荐模型、竞价出价、用户画像、因果转化模型或线上实验；有限整数枚举只是小型资源分配教学。</p>
