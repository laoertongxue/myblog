</details><h2 id="core-06-预售净留存与小型来源联合分配">core-06
预售净留存与小型来源联合分配</h2>
<p>覆盖 A07
的剩余预售链，并给出有边界的MRP/APS/多地点资源联算。目标是分清“取消后的净需求”“防风险的备货量”和“从哪儿补”。</p>
<h3 id="订单数不等于最后留存数">1 订单数不等于最后留存数</h3>
<p>除了已确认的OMS30瓶，新增一组独立预售100瓶。它们不在POS390瓶中，也不在已确认30瓶中。三个可得情景是：留存40、70、90瓶，概率0.2、0.5、0.3。每个概率无单位，和必须等于1。</p>
<p><code>E[N] = Σ(概率 × 净留存)</code>。E[N]=0.2×40+0.5×70+0.3×90=8+35+27=70瓶。预期取消=100−70=30瓶。单个订单是否取消仍未知道，不能把均值当作真实执行名单。</p>
<p>按均值补货：原未取整缺口208.5788+新增预期70=278.5788瓶，向上整箱为282瓶。POS安全库存仅覆盖POS残差；这里新增预售的不确定性需另处理，不能既把它并入σ又重复完整对冲。</p>
<h3 id="用缺货和余货成本选择对冲量">2 用缺货和余货成本选择对冲量</h3>
<p>q是专门为新增预售准备的数量，单位瓶。N是情景留存瓶数。每少一瓶的教学损失Cu=8元；多一瓶的教学损失Co=2元。</p>
<p><code>C(q,N)=8×max(N−q,0)+2×max(q−N,0)</code>，单位元。每个情景各算一次，再按概率加权。</p>
<ul>
<li>q=42时，低情景多2瓶：4元；中情景少28瓶：224元；高情景少48瓶：384元。期望0.2×4+0.5×224+0.3×384=228元。</li>
<li>q=72时，低情景多32瓶：64元；中情景多2瓶：4元；高情景少18瓶：144元。期望12.8+2+43.2=58元。</li>
<li>q=90时，低情景多50瓶：100元；中情景多20瓶：40元；高情景刚好。期望20+20=40元。</li>
</ul>
<p>程序枚举q=0、6、12……102，最小值为90瓶、40元。最优90高于均值70，是缺货损失较高导致，不是“预测应改为90”。在原缺口上加此对冲量，208.5788+90=298.5788，整箱300瓶；也超过原收货容量210，因此这是<strong>待解决的冲突方案</strong>，不是已批准订单。</p>
<h3 id="为基础210瓶挑来源">3 为基础210瓶挑来源</h3>
<p>本节先只求不含新增预售的基础210瓶。PO表示向外采购；STO表示从远仓调入；WO表示本地生产。变量p、s、w都为瓶且是6的倍数。</p>
<p>约束：0≤p≤120；0≤s≤84−24=60；0≤w≤90。远仓必须保留24瓶。BOM还要求0.2w≤20kg、0.25w≤24m、w≤100个空瓶。本例生产能力90比材料上界更紧。</p>
<p>成本：<code>3p + 2s + 12×I(s&gt;0) + 1.5w + 20×I(w&gt;0) + 8×缺货 + 2×多余</code>。I条件成立为1，否则0。3、2、1.5是每瓶来源成本，12和20是启用来源的固定成本，缺货=max(210−p−s−w,0)，多余=max(p+s+w−210,0)。所有项单位都是元。</p>
<p>穷举所有可行整箱组合，最优p=60、s=60、w=90。费用180+120+12+135+20=467元，缺货和多余都为0。它不是先排一个固定优先级后得出的“最优”，而是实际比较了本模型所有离散候选。MES产能在11:00变为60，且新需求为222时，重算p=102、s=60、w=60，成本306+120+12+90+20=548元。</p>
<h3 id="项目-故障和答案">4 项目 故障和答案</h3>
<p>输入
<code>presale.csv</code>、<code>bom.csv</code>、config中的来源上界。输出
<code>presale.trials</code>、<code>joint_plan</code>、<code>late_joint_plan</code>。把情景概率之一改成0.9而不归一化，应该拒绝。把远仓保留量改84，调拨上界变0，最优应重新计算，而不是照抄STO60。将膜改为10米，生产不能超过40瓶，按箱规最多36瓶。</p>
<p>练习：为什么“282瓶、300瓶和210瓶”都出现？答案：210是不含新增预售的基础计划；282是新增预售按均值的总建议；300是采用90瓶对冲量的总建议。它们不是三张可同时相加的订单。</p>
