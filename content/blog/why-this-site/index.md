每个人都需要一个属于自己的角落。

在社交媒体泛滥的时代，我们习惯了在别人的平台上表达，用别人的规则思考。但那些内容不属于你——平台可以改变算法，可以修改规则，甚至可以消失。

## 为什么要自建网站

**内容所有权。** 你的文字、你的思考，应该在你控制的地方。Markdown 文件存在 GitHub 上，谁也拿不走。

**长期主义。** 社交媒体追求即时反馈，网站追求长期积累。十年后，你的博客还在；你的微博早就被淹没了。

**结构化思考。** 写博客不是发朋友圈。它要求你组织思路，完整表达，反复修改。这个过程本身就是思考的深化。

## 技术选择

选择了 Hugo + Hextra，原因：

1. **简单** — 静态网站，不需要维护数据库
2. **快速** — 构建快、加载快、对服务器要求低
3. **可控** — 所有代码都在自己手里
4. **持久** — Markdown 是最稳定的内容格式之一

## 这个网站要做什么

不是技术博客，不是产品分析专栏，而是一个综合性的个人内容平台：

- **Weekly** — 每周的思考、发现、推荐
- **专题** — 系统性的知识整理
- **Blog** — 独立的长文

内容会涉及产品、供应链、AI、管理、读书，以及任何值得记录的东西。

## 最后

开始比完美重要。先做起来，再慢慢完善。
