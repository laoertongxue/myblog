# 12Lab V1.2 页面样式实施计划

目标：将用户提供的 V1.2 规范与第三版十页设计稿落实到现有 Hugo 内容站。

设计决策：采用固定 260px 左栏、白色内容区、蓝灰强调色和衬线标题；阅读正文最大 860px。专题稿的常驻目录与规范冲突时，以 V1.2 浮动目录为准。保留现有内容与路由，不把稿中的示例文章、统计或个人信息当成真实数据。没有提供独立头像素材，使用可配置的中性头像。

- [x] 公共布局：layouts/baseof.html、layouts/_partials/lab/、assets/css/custom.css，统一侧栏、搜索、导航和移动端菜单。
- [x] 十种页面：home、blog、weekly、topics、search、about 模板；归档与标签页同步使用公共样式。
- [x] 阅读交互：assets/js/lab.js，目录默认收起，Escape/外部点击关闭、章节高亮；上下篇位于正文之后。
- [x] 搜索：Hugo 生成已发布内容 JSON，本地搜索标题、正文及标签，支持类型筛选和空状态。
- [x] 验证：hugo --minify；浏览器桌面/移动端查看全部页面类型，验证目录、搜索、导航与横向溢出；保存截图。
