# 12Lab V1.2 样式调整验收

依据用户提供的《12Lab 博客设计规范 V1.2》和第三版十页设计稿，实现首页、博客列表/详情、Weekly 归档/详情、专题列表/首页/文章、搜索、关于页。归档、近况、友链和标签页继承公共布局。

## 实现

- 桌面固定 260px 浅灰侧栏、圆形头像、五项主导航、搜索、社交入口与轻量页脚。
- 白色主内容区、衬线标题、蓝灰强调色、文字列表与细分割线；正文最大宽度 860px。
- 目录默认关闭，点击显示半透明浮层；支持章节高亮、锚点跳转、Escape 和外部点击关闭。专题文章稿与规范冲突处采用 V1.2 浮动目录规则。
- 上下篇在正文之后；专题导航按当前专题及章节权重排序。
- 搜索已发布博客、Weekly、专题文章和专题介绍，支持内容类型筛选与空结果提示。
- 手机侧栏改为折叠菜单，专题章节导航可折叠。

## 素材与内容边界

没有独立头像、封面和作者照片素材，使用本地中性头像（`static/images/avatar.svg`）。可通过 `params.avatar` 替换。文章支持 `cover` 参数，未配置时不显示图片。没有复制设计稿中的示例文章、阅读量、评论数或联系邮箱；邮箱入口仅在 `params.email` 配置后显示。

保持 Hugo 对未来发布日期的处理规则。当前内容少于稿中的示例，列表密度会随真实内容数量变化。
