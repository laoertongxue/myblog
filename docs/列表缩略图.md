# 列表缩略图

新增、重新生成或替换的文章封面、banner 和正文插图统一交付为 **900 × 383px**，精确比例为 **900:383**，约为 2.35:1，供博客与微信公众号共用。`2.35:1` 只是近似说明，生成和验收以实际像素 `900 × 383` 为准。

原尺寸例外严格限定为本次核查的 **39 张历史源图（博客 23 张、专题 16 张）**，由 `scripts/legacy-image-sources.json` 固定源路径、尺寸、SHA-256 和公开路径。只有文件字节与清单完全一致时才可保留原尺寸；未来新增或替换历史文件也须遵守新规格，不得自动扩充清单。浏览器检查自动要求新图精确为 `900 × 383`，或与这份有限清单中的尺寸、哈希完全匹配。

技术图优先使用可编辑的矢量源组织文字、表格与连线，再导出规定尺寸的位图。信息过密时应拆成多张图或重新排版，不能把一张高图直接缩小塞进宽幅画布，也不能靠拉伸或裁切换比例。交付前同时核对实际尺寸、中文字和图例的可读性。

博客、Weekly、专题文章以及专题首页均支持图片预览。标题、日期、摘要仍然显示，列表最多展示三张 **900:383 缩略图**。首页、标签和分类列表使用相同规则。列表框比例由 `assets/css/custom.css` 的 `--lab-image-ratio` 统一维护。

新配图可完整铺满预览区域。清单内的 39 张历史图保留完整原文件，列表预览按原比例放入宽幅框，必要时留白。SVG、截图和外链图也不能裁切或拉伸，但这些类型不会自动获得新图尺寸例外。**文章封面和正文不套用列表框**：默认按原始比例占满内容栏宽，高度自动适配，避免把技术图的文字压小。头像和导航图标保留各自尺寸。

图片与 Markdown 放在同一个文章 bundle 中，例如：

```text
content/blog/my-post/
  index.md
  images/
    00-cover.png
    01-flow.png
    02-data-model.png
```

在 `index.md` 顶部的 YAML 中指定列表图片及顺序：

```yaml
images:
  - images/00-cover.png
  - images/01-flow.png
  - images/02-data-model.png
```

此字段与 `title`、`date`、`description` 等处于同一层级。图片数量可以是一张或多张，超过三张时列表只取前三张。

所有列表缩略图默认保留完整画面，不再需要设置 `thumbnailFit: contain`。旧文章可以保留该字段，但它不再决定显示方式。

选择优先级：

1. 配置了非空 `images`：按指定顺序展示。
2. 未配置 `images` 但配置了 `cover`：展示封面。
3. 两者均未配置：自动读取当前文章 bundle 内的图片，按资源名称排序取前三张。可用 `00-`、`01-` 等前缀控制顺序。
4. 没有图片：只展示文字，不放占位图。

Weekly 的图片放在 `content/weekly/期号/`；专题文章放在对应章节的 bundle 中。专题自身的缩略图写在 `content/topics/专题名/_index.md` 的 `images` 中，图片放在该专题文件夹。

站内共享图片也可使用 `/images/example.jpg`（对应 `static/images/example.jpg`），或者 `assets/` 下资源的相对路径。支持完整 HTTPS 图片地址，但外部图片不会经过本站压缩，可靠性由图片来源决定。推荐 bundle 本地图片，Hugo 会按 **324 × 138、540 × 230、900 × 383** 三档边界使用 `.Fit` 生成 WebP 缩略图；它们是容纳边界，不强行改变源图比例，`srcset` 标注每个候选的实际宽度。首张图片优先加载，其余懒加载。SVG 保持矢量格式。

指定列表图片不会自动插入正文。封面或普通插图可写为：

```markdown
![文章封面](images/00-cover.png)
```

文字密集的技术图使用明确的原图链接，让读者能在手机上打开并放大阅读：

```markdown
[![流程与关键字段说明](images/01-flow.png)](images/01-flow.png)
```

只包裹一次已有图片，不重复嵌套链接。正文显示缩放后的 WebP，链接指向完整原图。原图入口只是补充放大阅读，不能代替正文可读性；新图仍须在规定尺寸内保留清晰文字，密集内容应拆图或重新排版。

全站使用顶部导航与居中单栏，桌面宽度为屏幕的 80%，最大 1440px；手机两侧各留 20px。电脑和手机统一使用「页码、省略号、左右箭头」分页，每页 10 篇。详情页保留悬浮目录，不占据侧栏。

正文中的本地图片也会经过 Hugo 图片管线；宽度超过 1440px 时等比缩小并输出 WebP，保留完整画面与原始比例。正文和封面使用内容栏宽与自动高度，历史竖图可自然增高；新 `900 × 383` 图片也按自身比例显示。构建不改写源图，便于查看原图与复用。仅上述清单中原字节不变的 39 张历史源图保留原尺寸，详见 [2026-10-28 图片规格核查](2026-10-28-图片规格核查.md)。
