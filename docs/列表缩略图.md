# 列表封面与正文配图

每篇文章只展示一张列表封面，封面文件必须为 **900 × 383px**，精确比例为 **900:383**，约 2.35:1。这个尺寸要求只适用于封面；**其他正文配图使用各自原始尺寸与比例，不要求统一为宽幅图片**。

封面需从内容与版式重新设计，优先保留可编辑的 SVG 源，再导出实际 `900 × 383` PNG。本次六张封面的设计源放在 `assets/cover-sources/`，PNG 放在对应文章 bundle。不要直接把原高图裁成宽幅、拉伸变形或用大块留白补成新尺寸。标题、图形与少量关键文字应适合缩略图阅读。

文章 bundle 示例：

```text
content/blog/my-post/
  index.md
  images/
    00-cover.png         # 唯一封面，900 × 383
    01-flow.png          # 正文图，保留原尺寸
    02-data-model.png    # 正文图，保留原尺寸
```

在 front matter 中明确指定唯一列表封面：

```yaml
images:
  - images/00-cover.png
```

此字段与 `title`、`date`、`description` 同层。指定列表封面不会自动插入正文；正文首图也使用这张图片：

```markdown
![文章封面](images/00-cover.png)
```

列表只取一张图片，选择优先级为：

1. 配置了 `cover` 时使用该封面。
2. 否则使用非空 `images` 的第一张；正常文章只配置这一张。
3. 两者均无时，按文章 bundle 资源名称排序取第一张。应使用 `00-` 前缀并优先显式配置，防止误选技术图。
4. 没有图片就只展示文字，不生成占位图。

首页、博客、Weekly、专题及标签/分类列表共用紧凑的图文条目。日期和标题位于上方；下方图文区在桌面上为**单封面在左、摘要信息在右**，摘要、继续阅读、阅读时长和栏目归于同一信息列，与封面顶部对齐。封面列宽取内容区宽度的 **46%** 与 **540px** 中的较小值，两列间距为 **32px**；条目和摘要之间的留白收紧，保留原有暖色与文字层次。

屏幕宽度**不超过 900px** 时，图文区切换为封面在上、摘要信息在下。封面保持最大 540px，在手机上占满可用内容栏宽；没有封面的条目只展示全宽信息，不保留空的图片列。日期和标题始终位于图文区上方，不被挤入摘要列。

模板保留 `.row-body h2` 标题，使用 `.row-content` 包含封面和 `.row-summary` 摘要信息，避免影响已有标题链接与列表发现逻辑。封面显示比例继续由 `assets/css/custom.css` 的 `--lab-image-ratio` 维护。Hugo 使用 `.Fit` 按 **540 × 230、900 × 383** 两档边界生成 WebP，`srcset` 标注实际宽度。CSS 使用 `object-fit: contain`，不裁切、不拉伸。小尺寸导出存在整数像素取整，封面源文件仍须精确为 `900 × 383`。首张封面优先加载，其他封面懒加载。

Weekly 图片位于 `content/weekly/期号/`；专题文章图片位于对应章节 bundle。专题自身封面配置在该专题 `_index.md` 中。头像与导航图标保留自己的尺寸。旧 `thumbnailFit` 字段可以保留，但不控制显示方式。

正文技术图、截图、表格图、SVG 和外链图均按自身比例完整显示，不受封面尺寸限制。正文默认占满阅读栏宽、高度自动适配，竖图可自然增高。本地位图仍经过 Hugo 图片管线，宽度超过 1440px 时等比缩小并输出 WebP；文件源图不被改写，SVG 保持矢量格式。共享图片与 HTTPS 外链仍可使用，但外链可靠性取决于来源。

文字密集的技术图可提供原图链接，支持打开并放大阅读：

```markdown
[![流程与关键字段说明](images/01-flow.png)](images/01-flow.png)
```

不要重复嵌套已有图片链接。原图入口只补充放大阅读，不能代替正文可读性；信息过密时可以按内容需要拆图或重排，但不能为满足封面比例而处理正文图。正文尺寸没有历史例外清单或哈希白名单门槛。

文章上下篇导航在所有屏幕宽度下都保持左右两列：上一篇在左、下一篇在右；第一篇和最后一篇保留缺项的空格。长标题在自己的列内换行，不能把两项上下堆叠或交换位置。

全站使用顶部导航与居中单栏，桌面宽度为屏幕的 80%，最大 1440px；手机两侧各留 20px。列表继续使用每页 10 篇的编号分页。详情页保留悬浮目录，不占据侧栏。

浏览器检查分别验证封面实际尺寸、每条列表只有一张封面、桌面图左文右与顶部对齐、900px 断点下的上下堆叠和手机栏宽适配，以及正文原比例、完整加载、原图链接和上下篇位置。检查通过与逐图清单见 [2026-10-28 图片规格核查](2026-10-28-图片规格核查.md)。
