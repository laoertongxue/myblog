# 列表缩略图

博客、Weekly、专题文章以及专题首页均支持图片预览。标题、日期、摘要仍然显示，列表最多展示三张方形缩略图；完整正文和原图不受影响。

图片与 Markdown 放在同一文件夹，例如：

```text
content/blog/my-post/
  index.md
  park.jpg
  coffee.jpg
  sunset.jpg
```

在 `index.md` 顶部的 YAML 中指定图片及顺序：

```yaml
images:
  - park.jpg
  - coffee.jpg
  - sunset.jpg
```

此字段与 `title`、`date`、`description` 等处于同一层级。图片数量可以是一张或多张，超过三张时列表只取前三张。

选择优先级：

1. 配置了非空 `images`：按指定顺序展示。
2. 未配置 `images` 但配置了 `cover`：展示封面。
3. 两者均未配置：自动读取当前文章文件夹内的图片，按资源名称排序取前三张。可用 `01-`、`02-` 等前缀控制顺序。
4. 没有图片：只展示文字，不放占位图。

Weekly 的图片放在 `content/weekly/期号/`；专题文章放在对应章节的文件夹。专题自身的缩略图写在 `content/topics/专题名/_index.md` 的 `images` 中，图片放在该专题文件夹。

站内共享图片也可使用 `/images/example.jpg`（对应 `static/images/example.jpg`），或者 `assets/` 下资源的相对路径。支持完整 HTTPS 图片地址，但外部图片不会经过本站压缩，可靠性由图片来源决定。推荐同目录图片，Hugo 会自动生成 520 × 520 WebP 缩略图，并在列表中懒加载。

指定列表图片不会自动插入正文。如需在正文显示，仍写 `![图片说明](park.jpg)`。

全站使用顶部导航与居中单栏，桌面宽度为屏幕的 80%，最大 1440px；手机两侧各留 20px。电脑和手机统一使用「页码、省略号、左右箭头」分页，每页 10 篇。详情页保留悬浮目录，不占据侧栏。

正文中的本地图片也会经过 Hugo 图片管线；宽度超过 1440px 时缩小并输出 WebP，保持原始比例。SVG 保持矢量格式。
