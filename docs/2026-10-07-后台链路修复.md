# 内容与发布链路修复

本项目没有动态管理后台。此次修复覆盖本地写作、校验、自动发布和服务器部署权限。

## 修复项

1. 四个 archetypes 使用 `time.Now.Format`，修复对字符串 `.Date` 调用 `.Format` 导致 `hugo new` 失败。
2. 使用 `hugo list all` 的 CSV 解析结果校验日期、博客 slug，支持合法带引号日期，不再用正则猜测 front matter；草稿允许暂缺字段，正式及未来文章仍必须满足契约。无效 YAML/TOML 语法仍会被 Hugo 拒绝。
3. 发布后的 HTTP 探针带 8 秒超时，最多 3 次尝试。状态码、连接/TLS/DNS/超时错误以及内容校验失败都进入回滚；SIGTERM 同样恢复切换前目标。
4. 回滚使用切换前实际读取的 current 链接，而非目录时间。失败上传目录不会成为回滚候选；current 是普通目录时拒绝发布，不再自动删除。
5. 构建生成全部文件 SHA-256 清单。远端核对文件集合、校验值及 HTML 数量，全部通过后才能切换。切换后核对首页、文章、搜索、索引、CSS、JS、图片候选、RSS、sitemap、robots 和真实 404 的状态及响应内容。
6. CI 改用 deploy12lab 专用账户、独立密钥和固定 ED25519 主机指纹。账户无 sudo，仅管理站点目录和自身 home；Caddy/SSH 系统配置由管理员管理。

额外保护：本地清理构建产物仅允许 public 或 .hugo-check，拒绝符号链接；避免 OUT 参数误删其他目录。

## 自动检查

- `python3 scripts/check-content-workflow.py`：隔离目录真实新建博客、周刊、专题章节，校验生成日期、slug，验证缺日期/slug 的正式或计划文章会失败，而缺元数据草稿不阻断。
- `python3 scripts/check-deploy-release.py`：11 个隔离测试，覆盖缺文件、篡改文件、HTML 数量不符、HTTP 500、返回旧内容、网络失败重试、真实 404、SIGTERM、普通 current 拒绝删除、CSS/JS/srcset/搜索索引缺失，以及正常发布。
- 以上全部接入 `make check` 和 CI；故障注入不对生产站点执行。
- `scripts/check-static-output.py` 新增 CSS、JS、srcset、站内绝对 URL 与搜索索引依赖检查。

## 运维说明

- 主机指纹核对来源是原有可信管理员 SSH 连接，保存在 scripts/deploy-known-hosts；不是未经核验的 ssh-keyscan。
- 自动发布使用 GitHub Secret `DEPLOY_SSH_KEY_DEPLOY12LAB`，私钥不能提交仓库或输出到日志。
- 管理员私钥继续用于维护；不授予发布账户系统配置或服务重载能力。
- 原始写作示例中的 `date: '2026-10-07'` 现在可以正常校验，不再要求人为去掉日期引号。
- 断电或 SIGKILL 无法由进程捕获；current 的原子切换避免半写链接，切换前目标另存 previous-release.txt 供恢复。外部强制终止不等同于可捕获的网络/HTTP 失败。
