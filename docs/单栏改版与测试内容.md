# 单栏改版与测试内容

2026-09-23 按新的样式要求统一为浅米色背景、顶部导航、居中单栏。桌面容器为屏幕宽度的 80%，最大 1440px；手机两侧各留 20px。正文与列表使用同一内容边界，不再额外缩窄，也不保留左右侧栏。

## 导航与分页

导航配置仍以 `hugo.toml` 为唯一来源。菜单项的 `params.placement` 控制顶部位置：`leading` 为左侧、`quick` 为右侧（模板不读任何图标字段，菜单里的 `params.icon` 已于 2026-10-12 删除）。顶部直接展示首页、搜索、Weekly、专题、博客与右侧的关于、近况、友链；页脚只提供文章归档、RSS、版权与隐私和网站地图。

首页、博客、Weekly、专题列表与专题章节列表统一使用每页 10 项（`hugo.toml` 的 `pagination.pagerSize`；浏览器检查直接读这个值，不在脚本里写死）。分页显示首尾页、当前页及相邻页，中间使用省略号，前后页为箭头。电脑与手机行为一致，无 JavaScript 时也能翻页。原手机滑动自动加载已根据本次要求移除。

文章目录保留展开、收起、章节跳转、当前位置高亮、Escape 关闭和点击外部关闭。专题章节导航位于文章下方，默认折叠，不占侧栏。

## 验证

- `make check`：生产构建、内容契约、43 篇隔离分页测试、缩略图来源与数量上限、全站本地图片和文章链接、专题系列真实回归、发布故障注入，最后是浏览器检查。
- 浏览器检查：六个 `async (page, ctx) => {}` 闭包由 `scripts/run-browser-checks.mjs` 统一执行（自带 1316 端口的静态服务，行为对齐 Caddy）。手动运行 `npm run check:browser`，`make check` 会自动带上它们。`scripts/check-design-browser.js` 覆盖 19 条路由 × 320/390/768/1440/1920px、图片实际解码、首页与各栏目分页、目录、搜索和无 JavaScript 翻页。

构建输出与浏览器截图不提交。

## 移动端导航与详情信息

宽度不超过 760px 时，顶部显示站名和菜单按钮。菜单使用原生 dialog 浮层，支持关闭按钮、遮罩、Escape、焦点返回与切换到桌面时自动关闭。菜单数据仍来自 hugo.toml。手机页脚隐藏许可说明、网站地图与备案信息，保留版权署名、归档、RSS 和回到顶部。

桌面内页首个入口显示「← 拾贰画生」。文章标题下按 Hugo 的 WordCount 与 ReadingTime 显示正文字数及阅读时长；不显示没有真实数据来源的评论数量。

浏览器检查：`scripts/check-mobile-navigation.js`（移动端菜单与页脚、阅读信息、目录），以及 `check-design-browser.js`、`check-adversarial-ui.js`、`check-agent-series-browser.js`、`check-thumbnail-fit-browser.js`、`check-resource-loading.js`。
