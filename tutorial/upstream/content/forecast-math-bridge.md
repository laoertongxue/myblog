# 数学桥梁：先会算，再认识符号

这是一门教程，不是专题文章集合。学习顺序是“读懂问题 → 手算 → 操作数据 → 检查 → 解释”。你只需要高一数学；复杂模型首先学会输入、输出、假设与验证，再决定是否继续深究算法。每次学习建议120分钟：阅读25分钟、手算20分钟、实验50分钟、检查15分钟、记录10分钟。允许分两天完成，不以读完页面代替通过作业。

## 第一站：下标不是乘号，帽子表示预测

y₃表示第3天的实际需求，不是y乘3；本节以“件/日”为记录口径，每个y是某一天的需求件数。ŷ₃表示对第3天的预测，单位仍为件。ŷ(T+5|T)读作“站在T时点，对五天后的预测”。T是预测发起的日期，5是向前的天数；竖线右边说明我们站在哪里，左边说明要预测哪一天。若今天是11月6日，T+5就是11月11日。未来实际天气尚未知，预测时不能偷偷使用11日的观测温度。

特征是输入信息，例如价格、周几；参数是模型学出的规则，例如价格每增加1元，预测变化多少；目标是要预测的数量；序列键是区分门店和商品的编号。一个模型可以有很多参数却只预测一条序列，也可有多个类别输入而仍预测一个数，不能混称“多参数模型”。

## 第二站：求和、平均与权重

Σ读作“求和”，只是把指定的数字加起来。数据为10、12、14，Σy=10+12+14=36。n表示数字个数，这里n=3。平均值写作ȳ=Σy/n，因此36÷3=12。单位仍是件，而不是百分比。

加权平均=0.2×10+0.3×12+0.5×14=2+3.6+7=12.6。三个权重都不小于0，且0.2+0.3+0.5=1。因此结果在最小10和最大14之间。权重大意味着更重视，不代表数据更真实。只有用验证集比较后才能选权重，不能看测试结果后反复调整。

手算检查：把所有销量同时增加5，平均与加权平均都应增加5；把单位从件变成箱时，必须统一换算。

## 第三站：绝对值、平方与平方根

误差e=实际−预测。实际10、预测13时e=−3，负号代表高估。绝对值|e|=3，只问错多少；平方e²=9，大错受到更强惩罚。对误差−3、1，平均绝对误差MAE=(3+1)÷2=2件；均方根误差RMSE=√((9+1)÷2)=√5≈2.236件。√5表示“平方后等于5的非负数”，可用计算器开根号。

标准差描述数据围绕平均数的波动，与预测误差不是一回事。对10、12、14，均值12；偏离为−2、0、2；平方为4、0、4。把这三点当完整总体时，方差=(4+0+4)÷3=2.667件²，标准差=√2.667≈1.633件。用样本估计总体方差常除以n−1，这里是2，不是3。作业必须声明采用哪一种。

## 第四站：概率、条件概率与期望

概率是0到1之间的数。0.2就是20%，不是20。100个相似订单中平均约20个取消，不表示每批必定取消20个。若先有100单，第1天取消10单，剩90单；第2天又取消9单，那么第2天条件取消率是9÷90=10%，不是9÷100=9%。后者是对初始批次的事件占比。

上面的观测小表实际留下100−10−9=81单。若另把两个10%作为用于新批次的条件取消概率，那么新批次连续两天都留存的概率是0.9×0.9=0.81；对新的100单，期望留存为100×0.81=81单，但实际未必恰好81。这里第二个0.9是“已经活过第一天后”的留存概率，不需要假设两天取消事件独立。期望是多次重复的平均结果，可以是小数；不能把21.6件当作真实拣货指令。后续生存课会再说明发货、删失与这些概率估计的条件。

## 第五站：函数、指数、对数与logit

函数是“输入一个数，按规则输出一个数”。例如f(x)=2x+3，输入x=4得到11。x²是x乘自己，2³=2×2×2=8。对数问反问题：log₂8=3，因为2的3次方等于8。自然对数ln用约2.718的常数e作底，不必背常数的小数位，用计算器即可。ln(1)=0，ln(e)=1，ln只能输入正数，零销量不能直接取ln。

logit(p)=ln(p/(1−p))，其中p是无单位的概率，必须满足0<p<1。p=0或1时不能把它直接代入这条有限实数公式。p=0.5时，赔率p/(1−p)=0.5/0.5=1，对数为0；p=0.8时赔率=0.8/0.2=4，对数ln4约1.386。反过来，p=1/(1+exp(−z))，z是无单位分数，exp表示e的幂。z=0时p=1/(1+1)=0.5；z=ln4时exp(−z)=1/4，p=1/(1+1/4)=0.8。logistic模型用这条规则把任何有限实数z变成严格介于0和1之间的概率；它不是Cox模型的别名。链接函数定义可查[statsmodels官方GLM说明](https://www.statsmodels.org/stable/glm.html)。

这些是计算定义和教学演示，不是对真实供应链数据的结论。求和、均值预测、预测时点和误差评估可对照[FPP3作者教材第5章](https://otexts.com/fpp3/toolbox.html)；分类概率的评价另见[scikit-learn官方指标说明](https://scikit-learn.org/stable/modules/model_evaluation.html)。
