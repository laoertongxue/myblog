# 手算数据包

全部模拟数据，共9个CSV，面向教程阶段7、9—15及间歇需求。各文件可以直接用电子表格打开。

运行：python make_and_check.py。只用Python标准库，无安装、联网或账号。脚本重新生成CSV并执行8项数值断言，成功后生成verification.json。

对应答案：probabilities全4行Brier=0.2；presale前两天hazard均0.1，假设可接受时无发货反事实S2=0.81；restock目标第10天11.2件；cod发货先减100，质检合格再加18；leadtime A总体标准差0，B总体标准差√2；cross_elasticity +0.5/-0.3；pricing_paths收入80/88/86/80；newsvendor Q100/120/140成本100/60/60元。

restock的lag_p为条件于退货且最终可售的发货到可售时滞分布；本表只列对目标第10天有贡献的两项，不是完整退货记录。COD表的damaged行数量变动0表示不能加可售库存，损坏2件应记在非可售报损账。

intermittent序列[0,4,0,0,8,0,0,0]，8期2次非零，ADI=8/2=4期/次。非零大小[4,8]均值6；若把两个值视为完整等概率教学总体，方差[(4−6)²+(8−6)²]/2=4，CV²=4/6²=1/9≈0.1111。若用样本方差分母n−1会得到8和CV²=2/9，务必声明口径；此处不做小样本统计推断。ADI描述稀疏程度，CV²描述非零大小相对波动，两者不是同一个指标。

这些数据用于手算教学验证，不替代20,000单/10,000包裹等完整专项训练集；不得据这几行报告模型优于真实业务。
