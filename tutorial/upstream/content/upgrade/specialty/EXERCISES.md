# 四次动手练习：先一张纸，再运行代码

每次按“问题 → 小数手算 → 看字段 → 运行 → 对照 → 写局限”完成。不会高等数学也可以执行；遇到符号先把它翻译为一句话。

## 练习1：预售取消的正确分母

**问题**：100单预售，第1天10单取消、20单发货，第2天7单取消。第2天取消率是多少？

1. 纸上写：第2天仍在等待=100−10−20=70，条件取消率=7/70=10%。不能继续用100当分母。
2. 写下“如果两天自然取消率都10%、而没有发货，留存比例=0.9×0.9=0.81”。这不是实际等待池；实际第2天末等待63单。
3. 打开 `outputs/presale/independent_risk_table.csv`，筛 `group=ALL`、`age=1/2`。用本包真实生成的计数再算一次。模拟结果不要求恰好10%。
4. 打开 `survival.svg`，寻找信息性发货估计与oracle曲线的距离。回答：为什么发得越早，留下的订单看起来越不容易取消？
5. 在条件需求表挑一个当前年龄a的订单，查其SKU曲线。计算S(b)/S(a)，而不是再乘S(b)。核对跨60日强关时的规则。

**交付**：一张风险集复核表，一句话说明“无发货情景”依赖的假设，以及一个订单的条件留存计算。

**手算答案**：70、10%、81%、63单；如果已有80单、S(a)=0.72、S(b)=0.54，预计60单。不能把80×0.54=43.2当正确条件结果。

**验收**：风险集不为负；取消、发货、强关不重叠；S不增加；第60日强关不被解释为自然hazard。

## 练习2：退回了不等于能卖

**问题**：第8天发100件，第7天发50件；退货率20%、退回良率80%；可售回流时滞2天占40%、3天占60%。第10天预计可售回流多少？

1. 第8天批次贡献100×0.2×0.8×0.4=6.4件；第7天批次贡献50×0.2×0.8×0.6=4.8件；共11.2件。期望可有小数，实物库存没有0.2件。
2. 从 `data/returns/events.csv` 挑一条有restocked的实体，写出发货、申请、到仓、质检、上架五个日期。计算发货到可售时滞，不只计算退回运输时间。
3. 在 `test_cohort_predictions.csv` 核对p_eventual_restock=p_return×conditional_quality_yield。
4. 在 `test_cohort_daily_restock.csv` 累加预期和实际回流。解释为什么某天误差变小，不代表每一天都变好。
5. 在 `state_conditioned_next7_daily.csv` 看当前状态预测。为何已经restocked的订单未来不能再加一次？

**交付**：一条实物事件链、一个日回流复算、分清“预计供应”和“现有可售”的两列。

**手算答案**：11.2件；若不可再售食品良率=0，预计可售回流也=0。

**验收**：质检前不入可售；单件未来回流总概率≤1；训练窗口未成熟负例留空；食品情景全部0。

## 练习3：概率与实物两本账

**问题**：四个预测为0.8、0.2、0.6、0.4，实际为1、0、0、1。平均平方误差是多少？

1. 分别算0.04、0.04、0.36、0.36，相加除以4=0.2。Brier越小越好，但必须与同一批样本上的基线比较。
2. 打开 `cod/test_calibration.csv`。先看每组n，再比较平均预测和实际拒收率。空组不能说“0%拒收”。
3. 打开 `validation_threshold_costs.csv`，找模拟成本最低行。核对 `model_selection.json` 的阈值完全相同。不要用测试拒收结果改这个阈值。
4. 打开 `probability_ledger.csv`，比较原始概率、校准概率、实际结果。写清本次校准是否改善，而不是预设它必须改善。
5. 另做实物手算：初始100件，发100件后库存0；20件拒收，退回质检18件合格、2件报损，现有可售18件。发货当天不能只扣“预计能签收的80件”。

**交付**：Brier手算、带组样本量的校准解释、验证阈值和工作量、实物库存核对。

**手算答案**：Brier=0.2，前两条子集=0.04；实物最终18件，报损2件。

**验收**：概率在0–1；未完结包裹不是拒收0；实际出库按全部件数扣减；不声称假设复核60%有效就是因果证据。

**可选扩展**：在模型的成本函数里更改复核成本后，先写下新假设，再从头运行，把它作为另一个实验，不要挑测试效果最好的成本设定。若加入复核容量，需要重新设计决策问题，本包没有实现容量优化。

## 练习4：一张PO分三次到货

**问题**：订购100件，第10天收40件、第15天收30件、第25天收30件。第20天观察，交期是不是15天？

1. 第20天已收70、未收30，尚未收齐。完成时长未知，随访20天，右删失=1。第25天才有“收齐时长25天”的标签。
2. 在 `po/training_labels_asof179.csv` 找一条censored=1。核对订购=已收+未收；complete_age必须为空。
3. 打开 `po/test_po_predictions.csv`，查看P90留空的行。为何“空”比随便填最大历史天数更诚实？
4. 打开 `po/coverage_bounds.csv`，把有预测条数/全部条数写出来。覆盖上下界不等于置信区间，也不能只报好看的子集。
5. 对比固定交期、只看完成样本、KM。解释为什么只看已经收齐的PO容易漏掉慢单。

**交付**：一个部分收货账、至少一个未完成标签说明、一份含分母和上下界的P90报告。

**手算答案**：第20天完成时长未知；第25天收齐时长25天，不是首收10天或第二收15天。

**验收**：所有日期的订购=已收+未收；未收不为负；右删失不记为交期0；不可估计P90留空；不因模型结果自动改真实PO。
